# \# MoodTrack

# 

# A privacy-first college wellness platform for daily mood and stress tracking.
# 

# \## About

# 

# MoodTrack helps students track their daily mood and stress, understand their personal wellness trends, and identify sustained high-stress patterns.

# 

# The platform provides separate experiences for Students, Mentors, and Admins.

# 

# \## Features

# 

# \- Daily mood and stress check-ins

# \- Private daily notes

# \- 7-day mood and stress trends

# \- Personal stress heatmap calendar

# \- Complete check-in history and filters

# \- Automatic high-stress detection

# \- Alerts when stress is 4–5 for 3 consecutive days

# \- Mentor-specific student monitoring

# \- Mentor stress heatmaps

# \- Admin dashboard and analytics

# \- Student–mentor assignment management

# \- College-wide stress analytics

# \- Privacy-focused role-based access

# \- Responsive and modern UI

# 

# \## User Roles

# 

# \### Student

# Track and view only your own mood, stress, history, trends, and private notes.

# 

# \### Mentor

# Monitor only assigned students and receive alerts for sustained high-stress patterns. Private student notes are not visible.

# 

# \### Admin

# Manage students, mentors, assignments, alerts, and college-wide analytics.

# 

# \## Privacy

# 

# Student information is protected through role-based access. Students can only access their own data, mentors can only access their assigned students, and private student notes remain private.

# 

# \## Project Status

# 

# Built as a college hackathon project focused on student wellness, early support, privacy, and data-driven insights.
